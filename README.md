The funniest out-of-office auto-reply a houseplant would send, in one
line of 96 characters. No plea to be watered, no cactus cover, no
photosynthesis pun — a desk plant that has been ignored since March
answers with a revenge twist: it lives on the desk, it kept the receipt
of every ignored day, and today it returns the favour.

Entry for [The Houseplant Out-of-Office](https://make.fun/bounty/u-eager-stork-81-9647-the-houseplant-out-of-office-7c586047) on make.fun.

## The line

> Out of office: I live on this desk. You have ignored me since March. Today, I return the favour.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```

`main.ts` (Node 22, standard library only) copies `entry.txt` to
`/output/entry.txt`, which the grader gates at 1–120 UTF-8 characters.
